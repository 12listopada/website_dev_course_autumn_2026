
# Workshop 2 – CSS Basics

## Description
In this workshop, I learned how to style an HTML webpage using CSS.

## What I learned
- Linking an external CSS file to HTML
- Changing background and text colors
- Styling headings and paragraphs
- Using CSS selectors
- Adding borders and spacing
- Styling tables and forms

## Files
- index.html – main webpage
- styles.css – CSS stylesheet
