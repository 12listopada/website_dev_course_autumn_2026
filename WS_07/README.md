
# The Sleep Atlas

The Sleep Atlas is a four-page educational website about sleep, dreams, and healthy sleeping habits. It was created as part of the Website Development course at Laurea University of Applied Sciences.

## Pages

- **Home** – Introduction to sleep and overview of the website.
- **Sleep Science** – Sleep stages, brain activity, and circadian rhythms.
- **Dreams** – The science and mystery of dreaming.
- **Better Sleep** – Practical habits that support healthy sleep.

## Technologies

- HTML5 for page structure
- CSS3 for styling and layouts
- CSS Grid and Flexbox
- Media queries for responsive design

## Features

- Four interconnected pages
- Responsive layout for desktop and mobile devices
- Consistent navigation and visual design
- Images with alternative text
