
# Workshop 6 – Bootstrap

## Description
In this workshop, I learned how to use Bootstrap to create responsive webpages with pre-built components.

## What I learned
- Adding Bootstrap to an HTML project using a CDN
- Creating a responsive navigation bar
- Using the Bootstrap grid system
- Styling buttons with Bootstrap classes
- Creating cards with images and text
- Adding alert messages
- Using Bootstrap components for responsive design

## Files
- index.html – main webpage
- styles.css – CSS stylesheet
- mypicture.jpg – image used on the webpage
