
# Workshop 5 – Responsive Design

## Description
In this workshop, I practiced making webpages responsive so they work on different screen sizes.

## What I learned
- Creating responsive layouts with CSS
- Using Media Queries for mobile devices
- Changing a two-column layout into a single column on smaller screens
- Making images resize automatically
- Creating a responsive navigation menu
- Testing mobile layouts using browser developer tools

## Files
- index.html – main webpage
- styles.css – CSS stylesheet
