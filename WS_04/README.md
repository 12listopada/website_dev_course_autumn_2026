
# Workshop 4 – Page Layout

## Description
In this workshop, I practiced creating different webpage layouts using CSS Grid, Flexbox, and Media Queries.

## What I learned
- Organizing a webpage using header, navigation, main sections, and footer
- Creating a three-column layout with CSS Grid
- Arranging elements using Flexbox
- Using Media Queries to change styles based on screen size
- Creating navigation links to different sections of a webpage

## Files
- index.html – main webpage
- style.css – CSS stylesheet
